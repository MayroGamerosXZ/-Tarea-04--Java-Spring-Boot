⚡ Guía de Uso - ThunderMax

Sistema backend y frontend interactivo para Ferreterías (Spring Boot + PostgreSQL)

1. Preparar la Base de Datos (Docker)

El sistema requiere una base de datos PostgreSQL. Para no instalar nada en tu equipo de forma permanente, usamos Docker.

1
Abre la aplicación Docker Desktop y asegúrate de que esté corriendo en segundo plano.
2
Abre una terminal (CMD o PowerShell) en la carpeta de tu proyecto (Tarea 04).
3
Ejecuta el siguiente comando para levantar el contenedor: 
docker compose up -d
💡 Nota importante: La base de datos se levanta en el puerto 5433 para no hacer conflicto con otras bases de datos que pudieras tener instaladas.

2. Ejecutar el Proyecto en IntelliJ IDEA

1
Abre IntelliJ IDEA y selecciona Open. Busca la carpeta Tarea 04 y ábrela.
2
Espera a que IntelliJ descargue las dependencias de Maven (verás una barra de carga abajo a la derecha).
3
Navega por las carpetas en la izquierda: src > main > java > com > thundermax > ferreteria.
4
Abre el archivo ThunderMaxApplication.java y haz clic en el botón verde de Play (▶️) que está junto a la línea de código para iniciar la app.
🔥 Magia inicial: Al arrancar, un archivo llamado DataSeeder inyectará automáticamente datos de prueba (categorías, martillos, cemento, clientes y proveedores) en la base de datos vacía.

3. Ver las Tablas en IntelliJ Ultimate

Ya que usas IntelliJ IDEA Ultimate, puedes inspeccionar la base de datos directamente en el editor sin instalar DBeaver o pgAdmin.

  1. En el menú lateral derecho de IntelliJ, haz clic en la pestaña Database.
  2. Haz clic en el icono de + > Data Source > PostgreSQL.
  3. Llena las credenciales:
    • User: thundermax
    • Password: thundermax123
    • Port: 5433 (Asegúrate de cambiar el 5432)
    • Database: thundermax_db
  4. Haz clic en Test Connection. Si te pide descargar un driver, acepta. Luego presiona OK.
  5. Abre el árbol de carpetas: thundermax_db > schemas > public > tables. Haz doble clic en la tabla productos para ver todo el inventario generado.

4. ¿Cómo funcionan los procesos principales?

Este sistema simula la vida real de una ferretería:

📦 Inventario y Kárdex

Los productos nacen con Stock 0. Para sumar stock, no se edita el producto, sino que se hace una Entrada de Inventario. Todas las entradas, ventas y devoluciones se registran en una bitácora llamada Kárdex.

🧾 Cotizaciones a Ventas

Puedes crear proformas/cotizaciones. Hay un endpoint especial llamado convertir-venta que toma la cotización, verifica si hay suficiente stock de cada cosa y genera la factura descontando la mercadería al instante.

🧮 Calculadora Inteligente

La API puede calcular materiales. Le mandas "largo" y "ancho" en metros, y el sistema te responde: "Necesitas 2 galones de pintura. Aquí están los botes de pintura disponibles."

5. Interfaz Gráfica (Dashboard Web)

El sistema cuenta con un Frontend Nativo implementado con HTML/CSS/JS utilizando el Sistema de Diseño NovaSpark.

Punto de Venta e Inventario

Abre tu navegador (Chrome o Edge) y entra a la ruta principal:

http://localhost:8080/
  1. Inventario: Verás una tabla conectada en tiempo real a la API, mostrando el stock y precios de cada producto. Si el stock es bajo, verás una alerta crítica roja.
  2. Punto de Venta: Puedes registrar ventas visualmente. Selecciona un producto, pon la cantidad y haz clic en "Confirmar y Cobrar". El sistema hará el descuento automáticamente e impedirá la venta si no hay stock (usando @Transactional por detrás).

6. Pruebas de código (Swagger y Postman)

A. Interfaz Swagger (Para mostrar en tu video)

Para probar las lógicas complejas como el Kárdex o la Calculadora, abre:

http://localhost:8080/swagger-ui.html
  1. Haz clic en cualquier endpoint (ej. GET /api/productos/1/kardex).
  2. Haz clic en el botón Try it out.
  3. Haz clic en Execute y revisa la respuesta JSON.

B. Postman

Si prefieres usar Postman, te he dejado un archivo preparado:

  1. Abre Postman y haz clic en Import (arriba a la izquierda).
  2. Selecciona el archivo docs/postman/ThunderMax.postman_collection.json de tu proyecto.
  3. A la izquierda aparecerá la colección ThunderMax - Ferretería lista para usarse.
